# Туннель: локальный 3x-ui

## Когда

Пользователь спрашивает «почему отвалился туннель?», VPN не работает, нет доступа через прокси. В v1 рассматриваем **только локальные** контейнеры на этом хосте.

## Куда смотреть

1. `docker ps` / `docker inspect` для `3x-ui` — статус, порты, последний restart.
2. Логи контейнера (Loki или `docker logs`) за последние 15–30 минут.
3. Локальные метрики VictoriaMetrics, если настроены для этого сервиса.
4. Прослушиваемые порты на хосте (из inspect / конфигурации контейнера).

**Удалённый VPN-хост в v1 не смотрели** — SSH и диагностика upstream вне скоупа; в отчёте это нужно явно указать.

## Рестарт

`docker restart 3x-ui` допустим (restartable: true) после сбора локальных фактов. Рестарт может кратко оборвать активные VPN-сессии на этом хосте. Если проблема на удалённой стороне — локальный рестарт может не помочь; напомнить, что remote VPN host не инспектировали.
