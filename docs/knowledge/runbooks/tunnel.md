# Туннель: 3x-ui

## Когда

Пользователь спрашивает «почему отвалился туннель?», VPN не работает, нет доступа через прокси.

## Куда смотреть

1. `docker ps` / `docker inspect` для `3x-ui` — статус, порты, последний restart.
2. Логи контейнера (Loki или `docker logs`) за последние 15–30 минут.
3. Метрики VictoriaMetrics, если настроены для этого сервиса.
4. Прослушиваемые порты на хосте (из inspect / конфигурации контейнера).

## Рестарт

Рестарт `3x-ui` запрещён. Ответ — состояние сервиса `3x-ui` на хосте: статус inspect, ошибки в логах и плохие метрики. Команду рестарта не писать.
