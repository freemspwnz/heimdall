# Туннель: локальный sing-box / 3x-ui

## Когда

Пользователь спрашивает «почему отвалился туннель?», VPN не работает, нет доступа через прокси. В v1 рассматриваем **только локальные** контейнеры на этом хосте.

## Куда смотреть

1. `docker ps` / `docker inspect` для `sing-box` и `3x-ui` — статус, порты, последний restart.
2. Логи контейнеров (Loki или `docker logs`) за последние 15–30 минут.
3. Локальные метрики VictoriaMetrics, если настроены для этих сервисов.
4. Прослушиваемые порты на хосте (из inspect / конфигурации контейнеров).

**Удалённый VPN-хост в v1 не смотрели** — SSH и диагностика upstream вне скоупа; в отчёте это нужно явно указать.

## Рестарт

`docker restart sing-box` или `docker restart 3x-ui` допустимы (restartable: true) после сбора локальных фактов. Рестарт может кратко оборвать активные VPN-сессии на этом хосте. Если проблема на удалённой стороне — локальный рестарт может не помочь; напомнить, что remote VPN host не инспектировали.
