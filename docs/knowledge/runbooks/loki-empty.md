# Loki пустой: дырка покрытия

## Когда

Запрос в Loki вернул пустой результат (`no streams`), нет логов для контейнера, который пользователь ожидает увидеть; агент не нашёл строк в окне 15–30 минут.

## Куда смотреть

1. Убедиться, что контейнер вообще запущен (`docker ps`) — пустой Loki не значит, что сервис мёртв.
2. Проверить, есть ли у сервиса настроенный сбор логов в Vector / promtail (не все сервисы lab покрыты — это штатно).
3. Инвентарь: поле `logs` у сервиса; для postgres указан `{container="postgres"}` — если пусто, возможно, label другой или сбор не настроен.
4. `docker logs <container>` напрямую — обходной путь, когда Loki молчит.

## Рестарт

Рестарт Loki/VictoriaMetrics **не рекомендуется** (restartable: false) — это не лечит отсутствие логов у конкретного сервиса. Пустой Loki — **дырка покрытия observability**, не краш агента. В отчёте явно написать: «логи в Loki не настроены или label не совпадает», продолжить расследование через Docker inspect/logs.
